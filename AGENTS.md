# AGENTS.md — памятка для продолжения работы

Этот файл нужен, чтобы любой агент (или человек) мог продолжить работу без истории переписки.
Пользовательская документация — в `README.md`. Здесь — состояние, решения, ловушки и открытые вопросы.

## Что это

Android-приложение «Charge HUD» (пакет `by.charge.overlay`, Kotlin, minSdk 24):
- карта OpenStreetMap (osmdroid, без API-ключей) со станциями зарядки;
- маршрут A → B с остановками на зарядках при заданном запасе хода (адрес или точка на карте);
- встроенная навигация: линия, баннер манёвров, голос, поворот карты по движению, полоса станций слева;
- кнопка «Яндекс Навигатор» для внешнего маршрута;
- вход в Open Charge Map (OCM) по логину и паролю и получение API-ключа.

UI и документация на русском. Ветка работы: `arena/e0ddded8-charge`. Коммиты и push только в неё.

## Как проверять

- **Локальной сборки нет.** В песочнице нет JDK, а `dl.google.com`, `repo.maven.apache.org` и `services.gradle.org` недоступны. Не пытаться запускать `./gradlew` или `gradle`.
- **Проверка только через CI.** Каждый push запускает `build.yml`. Статус: `gh run list --branch arena/e0ddded8-charge`.
- **Логи и артефакты** из песочницы обычно не скачиваются (EOF). Смотреть шаги через `gh api repos/zigorminsk-debug/charge/actions/runs/<id>/jobs`.
- `workflow_dispatch` для этого токена возвращает 403.
- Проверки без сборки, которые делались: кросс-проверка ID в layout и строк в strings, сверка ссылок между модулями.
- Комментарии: при правках проверяйте, что в диффе нет изменений кода (`git diff -U0 | grep '^[+-]'` и фильтр по `//`).

## Решения, которые уже приняты

- Карта — OSM через osmdroid, без ключей. Маршрут внешним приложением — Яндекс Навигатор (пользователь выбрал вариант 1 через ask_user).
- Ключ подписи лежит в Git (`signing/`) по явной просьбе пользователя, не в GitHub Secrets.
- Репозиторий **публичный**, и ключ подписи в нём есть. Пользователь предупреждён. Видимость не менять без решения пользователя.
- Радиус поиска станций — 15 км (`MainActivity.SEARCH_RADIUS_KM`, README). Коммит `5a9e02d` ставил 5 км. **Расхождение ещё не подтверждено пользователем.**
- Пароль OCM не сохраняется. Сохраняется только ключ (SharedPreferences `settings`, поле `ocm_api_key`). Cookie и WebStorage OCM очищаются после получения ключа.
- Открытый HTTP для OCM запрещён: cleartext не разрешать (`usesCleartextTraffic` и network security config с cleartext не добавлять). Вместо этого `OcmAuth.httpsUpgrade` переводит http-адреса openchargemap.org на https.
- Станции «выведена из эксплуатации» (DISUSED) не показываются. Станции «не работает» (BROKEN) — не берутся в остановки маршрута, но видны на карте с красной обводкой и в полосе.
- Полоса слева показывает все станции в коридоре 3 км вдоль маршрута. Остановки планировщика помечены ★.

## Ловушки (уже наступали)

- JUnit 4: `assertNotNull` возвращает `void` и не даёт smart cast. Использовать `!!` или `assertTrue`. Из-за этого падал прогон `42074860064`.
- TextToSpeech: `tts?.language = …` не работает, потому что `setLanguage` возвращает int. Вызывать явно `tts?.setLanguage(…)`.
- `maps.mail.ru` не является зеркалом Overpass (NXDOMAIN на телефоне). Не добавлять.
- Скрипт заполнения OCM ищет кнопку только внутри формы с полем пароля. Поиск по всей странице кликал «Sign In» в шапке, и страница перезагружалась пустой.
- OSRM принимает координаты в порядке `lon,lat`. В приложении `LatLon` хранит `lat, lon`.
- Ошибки HTTP и сети: `Http.get` бросает `IOException` при коде не 2xx. Ловить и показывать текст, а не падать.
- Песочница не достаёт nominatim, openchargemap.org, OSRM и router. Ответы этих сервисов не проверялись вживую. Проверять на телефоне.
- Документация OCM на `openchargemap.org/site/develop/api` перенаправляет на вход. Анонимно не получается.
- Яндекс Навигатор: схема `yandexnavi://build_route_on_map` и пакет `ru.yandex.yandexnavi` не проверены на устройстве.
