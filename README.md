# Charge HUD — зарядные станции поверх Яндекс Навигатора

Android-приложение показывает поверх Яндекс Навигатора полупрозрачный слой с зарядными станциями:
Malanka, BatteryFly, forEVo, Evika!, Zaryadka, byCharge, GO TO-U, Tesla и станции без известного бренда.
Слой состоит из радара, полосы «ближайшая станция» и кнопки «Маршрут».

## Что важно знать сразу

- **Приложение не встраивается в карту Яндекс Навигатора.** Android не даёт одному приложению рисовать внутри чужой карты.
  Вместо этого слой — это системное окно поверх всех приложений (`TYPE_APPLICATION_OVERLAY`) и служба переднего плана.
  Сам Навигатор не меняется и не модифицируется.
- **Радар не привязан к масштабу карты Навигатора.** Масштаб Навигатора неизвестен, поэтому радар — самостоятельный индикатор
  (кольца 2.5 / 5 / 10 км, станции дальше 10 км показаны стрелками на краю).
- **Кнопка «Маршрут»** открывает Яндекс Навигатор по схеме `yandexnavi://build_route_on_map?lat_to=…&lon_to=…`.
- **Данные о станциях** берутся из открытых баз OpenStreetMap (Overpass API) и Open Charge Map. Координаты в приложение
  не вшиты и не выдуманы. В репозитории лежит только справочник брендов `app/src/main/assets/networks.json`
  (названия, варианты написания, условные цвета).
  Качество данных зависит от открытых баз: статус «занята / не работает» и актуальные тарифы могут отсутствовать.
- Приложение не связано с Яндексом, Малинкой, BatteryFly и другими операторами.

## Установка

1. Скачайте `app-release.apk` со страницы **Releases** этого репозитория (или из артефактов последней сборки в Actions).
2. Разрешите установку из этого источника.
3. Откройте Charge HUD и выдайте разрешения:
   - «Поверх других приложений»;
   - геолокация;
   - уведомления (необязательно, но тогда не будет уведомления о работе службы).
4. Нажмите «Запустить слой», затем откройте Яндекс Навигатор. Слой остаётся поверх него.
5. Остановить слой можно кнопкой «✕» на полосе, в уведомлении или в приложении.

Пакет Яндекс Навигатора задан как `ru.yandex.yandexnavi` (`app/src/main/java/by/charge/overlay/nav/NavigatorLauncher.kt`).
Если на вашем устройстве он другой, поправьте константу `PACKAGE`.

## Обновления поверх установленной версии

Все сборки подписаны **одним и тем же постоянным ключом** `signing/charge-overlay.p12`.
`versionCode` равен числу коммитов в истории и только растёт. Поэтому новый APK ставится поверх старого без удаления приложения.
Если подпись сменится, Android откажет в обновлении, и придётся удалить приложение (данные будут потеряны).

Проверить подпись APK можно командой:

```bash
apksigner verify --print-certs app-release.apk
```

SHA-256 сертификата должен совпадать со значением в `signing/cert-sha256.txt`. CI проверяет это при каждой сборке.

## Сборка в GitHub Actions

Файл `.github/workflows/build.yml` запускается **автоматически**:

- при каждом push в любую ветку;
- при каждом pull request;
- ежедневно в 03:00 UTC по расписанию;
- вручную (кнопка Run workflow).

Шаги: unit-тесты → сборка release APK и AAB → проверка подписи → артефакт в Actions.
Для push в `main` дополнительно создаётся GitHub Release с APK.

Версия Gradle 8.9 ставится напрямую (`gradle/actions/setup-gradle`), поэтому `gradle-wrapper.jar` в репозитории не нужен.

## Ключ подписи лежит в репозитории — осознанное решение

По вашему запросу ключ хранится в Git (папка `signing/`), а не в GitHub Secrets. Это значит:

- любой, у кого есть доступ к репозиторию или его клону, может подписать APK этим ключом. **Держите репозиторий приватным.**
  Если он публичный, ключ публичен;
- пароли лежат в `signing/signing.properties` открытым текстом;
- если ключ утёк, сгенерируйте новый (`python3 tools/gen_keystore.py --force`). Пользователям придётся переустановить приложение;
- при желании пароли можно перенести в GitHub Secrets, а `.p12` оставить в репозитории.

Ключ создаётся скриптом `tools/gen_keystore.py` (RSA-2048, PKCS#12, срок действия около 32 лет).

## Сборка локально

Нужны JDK 17 и Gradle 8.9 (или Android Studio с JDK 17):

```bash
gradle --no-daemon test
gradle --no-daemon assembleRelease
```

Иконки перегенерируются скриптом `python3 tools/gen_icons.py`.

## Структура

```
app/src/main/java/by/charge/overlay/
  MainActivity.kt            экран разрешений, радиуса поиска и запуска
  overlay/OverlayService.kt  служба переднего плана и системное окно слоя
  overlay/HudView.kt         радар на Canvas
  data/Sources.kt            OSM (Overpass) и Open Charge Map: запросы и разбор ответов
  data/StationRepository.kt  загрузка из обоих источников, склейка дублей
  data/Networks.kt           нормализация названий операторов по справочнику брендов
  geo/Geo.kt                 расстояние и азимут
  location/LocationTracker.kt геолокация через LocationManager (без Google Play Services)
  nav/NavigatorLauncher.kt   deep link на построение маршрута в Яндекс Навигаторе
app/src/main/assets/networks.json   справочник брендов
app/src/test/                       unit-тесты (гео, бренды, разбор ответов)
signing/                            постоянный ключ подписи и его отпечаток
tools/                              генераторы ключа и иконок
```

## Ограничения

- Нет автозапуска после перезагрузки телефона: слой запускается вручную.
- Позиция окна фиксирована: верхний правый угол.
- Нужны GPS (или сеть) и интернет: станции загружаются при первом фиксе и при сдвиге на 2 км.
- Нет интеграции с Yandex MapKit: для неё нужен API-ключ Яндекса.
- Открытые базы могут не содержать часть станций или их актуальный статус и тарифы.
