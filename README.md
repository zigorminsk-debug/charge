# Charge HUD — карта зарядных станций

> **Для разработчиков и ИИ-агентов:** состояние работы, карта кода, как проверять сборку (локальной сборки нет, проверка через GitHub Actions), принятые решения и открытые вопросы описаны в [AGENTS.md](AGENTS.md). Читайте его перед любыми изменениями.

Android-приложение показывает карту OpenStreetMap с зарядными станциями: Malanka, BatteryFly, forEVo, Evika!, Zaryadka, byCharge, GO TO-U, Tesla и станции без известного бренда.
По нажатию на станцию открывается карточка с мощностью и разъёмами. Маршрут до станции можно построить **прямо в приложении** (кнопка «Ехать в приложении») или открыть в Яндекс Навигаторе.

## Что умеет

- **Карта станций** на собственной карте приложения (OpenStreetMap, osmdroid). Станции подгружаются вокруг центра карты в радиусе 15 км.
- **Маршрут A → B с зарядками по пути**: кнопка «Маршрут» на экране. Точки «Откуда» и «Куда» можно выбрать:
  - адресом (поиск Nominatim/OpenStreetMap, только Беларусь);
  - точкой на карте (долгое нажатие на карту в режиме выбора);
  - «Откуда» по умолчанию — ваше местоположение.
  Приложение строит маршрут, подбирает зарядки так, чтобы не превышать запас хода (его задаёте вы, по умолчанию 300 км, страховой остаток 50 км), и перестраивает маршрут через выбранные станции. Затем можно нажать «Ехать по маршруту»: во время пути приложение заранее предупредит голосом о каждой зарядке.
- **Остановки можно менять**: откройте станцию (на карте или в полосе слева) и нажмите «Добавить в маршрут» или «Убрать из маршрута». Маршрут перестроится через остановки впереди. Нельзя добавить станцию, которая не работает или выведена из эксплуатации, и станцию дальше 3 км от маршрута.
- **Статусы и разъёмы**: в карточке станции указаны статус («работает», «не работает», «статус неизвестен»), максимальная мощность и каждый разъём (тип, кВт, количество, статус). Станции, которые не работают, на карте обводятся красным и не попадают в маршрут; выведенные из эксплуатации скрываются.
- **Фильтр по сетям** — чипы сверху с количеством станций по каждой сети.
- **Встроенная навигация**:
  - маршрут строится по OSRM (открытые данные OpenStreetMap, без API-ключа) и рисуется линией на карте;
  - на карте во время навигации машина стоит на линии маршрута и смотрит по ходу движения;
  - масштаб зависит от скорости: на малой скорости карта приближается (город), на трассе отдаляется, чтобы видеть дорогу впереди; изменение плавное;
  - баннер сверху показывает следующий манёвр, расстояние до него и оставшиеся расстояние и время;
  - подсказки проговариваются голосом по-русски (нужен установленный на устройстве русский голос синтеза речи);
  - при подключённом внешнем питании GPS запрашивается максимально часто (без ограничения по времени и расстоянию), чтобы карта и повороты были актуальными; от батареи частота снижена (не чаще раза в 3 с и 10 м), чтобы экономить заряд;
  - если вы уехали с маршрута больше чем на 60 м, маршрут перестраивается (не чаще раза в 15 секунд);
  - при подъезде к цели в пределах 30 м приложение сообщает о прибытии;
  - экран не гаснет, пока идёт навигация.
- **Произвольная точка** — долгое нажатие на карту ставит точку назначения.
- **Яндекс Навигатор** — кнопка «Маршрут в Яндекс Навигаторе» открывает `yandexnavi://build_route_on_map?lat_to=…&lon_to=…`. Имя пакета `ru.yandex.yandexnavi` взято из знания о приложении и на устройстве не проверено.

## Что важно знать

- **Станции отображаются на карте самого приложения, а не на карте Яндекс Навигатора.** Сторонние приложения не могут рисовать станции на чужой карте, поэтому Навигатор используется только для построения маршрута, если вы выбираете этот вариант.
- **Карта** — OpenStreetMap через osmdroid, без API-ключей. Тайлы грузятся с серверов OpenStreetMap; их правила запрещают тяжёлое использование, поэтому для массового использования нужен собственный тайловый сервер.
- **Станции** берутся из OpenStreetMap (Overpass API). Запросы идут параллельно ко всем публичным зеркалам, первый успешный ответ побеждает. Если все зеркала не отвечают, на экране показана причина по каждому. Координаты станций в приложение не вшиты и не выдуманы. В репозитории лежит только справочник брендов `app/src/main/assets/networks.json`.
- **Статусы** в OSM заполнены редко. Актуальные статусы и разъёмы даёт **Open Charge Map**, но без ключа он отвечает 403. Ключ можно получить в приложении: «Ключ OCM» → «Войти и получить ключ», затем ввести e-mail и пароль от аккаунта openchargemap.org. Приложение откроет страницу входа OCM во встроенном окне, войдёт, найдёт ключ в списке ваших приложений и проверит его. Пароль не сохраняется: он передаётся только на сайт OCM. Если ключа ещё нет, приложение подскажет создать его (Register An Application) на той же странице. Ключ хранится только на устройстве; можно ввести его и вручную. Без ключа статусы помечаются как «статус неизвестен».
- **Ограничения планировщика**: батарея считается полной на старте; расход не зависит от рельефа, погоды и стиля вождения; отклонение до станции не больше 3 км; учитывается только запас хода, а не скорость зарядки и очереди.
- **Маршруты и адреса** — публичные серверы OSRM и Nominatim (`router.project-osrm.org`, `routing.openstreetmap.de`). Их доступность и правила использования могут меняться; для регулярного использования нужен собственный сервер OSRM.
- Статус «занята / не работает» и актуальные тарифы могут отсутствовать: это зависит от открытых баз.
- Приложение не связано с Яндексом, Малинкой, BatteryFly и другими операторами.

## Как пользоваться

1. Выдайте разрешение на геолокацию. Без него карта откроется на Минске.
2. Карта подгружает станции при движении и масштабировании.
3. Чипы сверху показывают сети. Нажмите сеть, чтобы видеть только её станции.
4. Нажмите на метку станции: откроется карточка с расстоянием, мощностью и разъёмами.
5. «Ехать в приложении» строит маршрут внутри приложения. Баннер сверху появится сам; кнопка «Завершить» останавливает навигацию.
6. «Маршрут в Яндекс Навигаторе» передаёт точку в Навигатор. Если Навигатора нет, приложение покажет сообщение.
7. Долгое нажатие на пустое место карты ставит точку назначения.
8. Кнопка с геолокацией в правой части экрана возвращает карту к вашему местоположению.

## Установка

1. Скачайте `app-release.apk` со страницы **Releases** (или из артефактов последней сборки в Actions).
2. Разрешите установку из этого источника.
3. Откройте Charge HUD и разрешите геолокацию.

## Обновления поверх установленной версии

Все сборки подписаны **одним и тем же постоянным ключом** `signing/charge-overlay.p12`.
`versionCode` равен числу коммитов в истории и только растёт, поэтому новый APK ставится поверх старого без удаления приложения.
Если подпись сменится, Android откажет в обновлении, и придётся удалить приложение.

Проверить подпись можно командой:

```bash
apksigner verify --print-certs app-release.apk
```

SHA-256 сертификата должен совпадать с `signing/cert-sha256.txt`. CI проверяет это при каждой сборке.

## Сборка в GitHub Actions

Файл `.github/workflows/build.yml` запускается автоматически:

- при каждом push в любую ветку;
- при каждом pull request;
- ежедневно в 03:00 UTC.

Шаги: unit-тесты → отчёты о тестах в артефакты → сборка release APK и AAB → проверка подписи → артефакты.
Для push в `main` дополнительно создаётся GitHub Release с APK.

Gradle 8.9 ставится напрямую (`gradle/actions/setup-gradle`), поэтому `gradle-wrapper.jar` в репозитории не нужен.

## Ключ подписи лежит в репозитории — осознанное решение

По запросу ключ хранится в Git (папка `signing/`), а не в GitHub Secrets. Это значит:

- любой, у кого есть доступ к репозиторию или его клону, может подписать APK этим ключом. **Сейчас репозиторий публичный, значит ключ тоже публичен.** Если хотите закрыть доступ, переведите репозиторий в приватный;
- пароли лежат в `signing/signing.properties` открытым текстом;
- если ключ утёк, сгенерируйте новый (`python3 tools/gen_keystore.py --force`). Пользователям придётся переустановить приложение;
- при желании пароли можно перенести в GitHub Secrets, а `.p12` оставить в репозитории.

## Сборка локально

Нужны JDK 17 и Gradle 8.9 (или Android Studio с JDK 17):

```bash
gradle --no-daemon test
gradle --no-daemon assembleRelease
```

## Ограничения

- Станции видны только в приложении, но не на карте Яндекс Навигатора.
- Нужны интернет и геолокация для загрузки станций и маршрутов.
- Открытые базы могут не содержать часть станций, их статусов и тарифов.
- Навигация простая: нет учёта пробок, полос, ограничений по высоте и весу; подсказки основаны на OSRM.
- Планировщик зарядок оценочный: см. «Ограничения планировщика» выше.
- Тайлы OpenStreetMap подходят для личного использования; при большой аудитории нужен свой сервер тайлов.
